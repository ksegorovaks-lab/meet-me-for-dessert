# Meet me for Dessert × Pinskiy & Co

Мобильный интерактивный прототип сервиса знакомств: свидание или дружба → анкета → симпатия → чат → приглашение в выбранный ресторан.

Интерфейс: HTML, обычный CSS и JavaScript, без Tailwind. Общая нижняя навигация на телефонах и планшетах; двухколоночная анкета от 744 px. Логотип, цвета и шрифты сохранены.

## Запуск

`pnpm dev` — открыть http://127.0.0.1:4173. Для браузерного предпросмотра зависимости не требуются; нужен Node.js 22+ для мобильных инструментов.


## Границы прототипа

- Все анкеты вымышленные; фотографии — иллюстрации из Unsplash.
- Симпатия в демоверсии сразу взаимна. Это демонстрация сценария, а не реальное взаимодействие.
- Анкета, фотография, сообщения и приглашения сохраняются только в localStorage текущего браузера. Фотографии до 3 МБ.
- Нет сервера аккаунтов, SMS, реальной доставки сообщений, модерации и бронирования. Жалоба прямо помечена как демонстрационная.
- Приглашение ожидает ответа. Кнопка «Демо: принять приглашение» демонстрирует согласование встречи. После принятия в ресторане из каталога открывается спецпредложение: −10% на ужин и оформление стола для свидания или дружеского знакомства. Тип встречи сохраняется в приглашении. Предложение можно повторно открыть из карточки встречи. Реальное согласие, бронирование и активация скидки не подключены.
- Каталог: 36 московских заведений и филиалов, 3 позиции в аэропортах, а также гастрокомплекс, сеть кофеен и доставка в общей категории. Источник: https://website.pinskiy.co/ → https://pinskiy.co/restaurants; проверено 4 ноября 2026. Индивидуальные первоисточники находятся в `dist/restaurants.js`. Для павильонов Лужников указан комплекс; точный павильон требуется уточнять на странице заведения. Состав отражает опубликованный каталог, а не внутренний реестр холдинга.
- Выбор ресторана в каталоге переносится в приглашение; его название, адрес и официальная ссылка сохраняются во встрече и чате. Старые приглашения без restaurantId продолжают показывать Loona.
- Шесть вымышленных анкет: три мужчины и три женщины; все доступны в обоих режимах, с фильтром по полу.

## Мобильные проекты

`ios/` — проект Xcode с поддержкой iPhone и iPad (`TARGETED_DEVICE_FAMILY = 1,2`). `android/` — проект Android Studio. Capacitor 8.6.0 использует локальный каталог `dist`, не загружает удалённый сайт внутри приложения. Bundle ID `com.meetmefordessert.app` — рабочее значение для разработки, перед публикацией нужно подтвердить принадлежность идентификатора.

После изменения интерфейса: `pnpm mobile:sync`. Открыть платформу: `pnpm mobile:ios` или `pnpm mobile:android`. Для установки инструментов: `pnpm install --frozen-lockfile`.

Создание проектов и синхронизация проверены. IPA/APK не собраны: на компьютере доступны только Command Line Tools, нет полного Xcode; Android SDK и среда сборки также не проверялись. Подписание, проверка на физических устройствах и публикация в магазинах предстоят. Backend и реальные аккаунты не подключены.

Справка по используемой оболочке: https://capacitorjs.com/docs/getting-started.

## Проверка размеров

Проверены все 16 уникальных размеров с пользовательских скриншотов: 466×678, 890×626, 402×874, 440×956, 393×852, 430×932, 420×912, 390×844, 428×926, 412×917, 700×840, 744×1133, 1440×960, 834×1194, 1024×1366, 1280×800. На экране знакомств нет горизонтального переполнения; нижняя панель доступна на всех размерах. Браузерная проверка не заменяет тестирование на реальных устройствах.

## Типографика и изображения

Akony и Astrum Cyrillic взяты из предоставленных архивов; Helvetica подключается как системный шрифт, затем Helvetica Neue, Arial, sans-serif. Системные файлы Helvetica не распространяются.

Сердце создаётся встроенным Imagegen. Финальный запрос и расположение ассета записаны в `ASSETS.md`.

## Файлы

`dist/index.html`, `dist/styles.css`, `dist/mobile.css`, `dist/app.js` — интерфейс без сборки. `dist/restaurants.js` — официальный каталог. `dist/fonts` — шрифты. `dist/assets` — изображения и иконки. `capacitor.config.json`, `ios/`, `android/` — мобильная оболочка. `server.mjs` — локальный сервер.
